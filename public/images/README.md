# Image Asset Guide

UI art is served as **WebP** (optimized). Paths are defined in `src/lib/customImages.ts`.

To replace art: drop a new `.webp` with the **same filename** (or convert PNG → WebP ~720–800px wide, quality ~70).

## Size tips
- Carousel cards: ~800w, under ~60KB
- Category thumbs: ~384w, under ~25KB
- Tracking steps: ~720w, under ~40KB
